Slide data

❧
Bullet List
Separate items with | and they render as styled bullets with a decorative marker.
Draft emails | Summarise threads | Coach writing
①
Numbered Steps
Use (1) (2) (3) inline and they render as elegant circled step numbers.
(1) Open Outlook (2) Click Copilot (3) Type prompt
—
Dash Bullets
Start each line with - for a clean dash bullet list. Use a new line per item.
- First point - Second point - Third point
─
Divider Rule
Type --- on its own line to insert a decorative horizontal rule between content sections.
First section content --- Second section content
📊
Chart
Wrap data in [chart:bar]...[/chart] (or line / pie) with one Label | value per line.
[chart:bar] Q1 | 45 Q2 | 62 Q3 | 58 [/chart]
H
Highlight
Wrap text in ==double equals== for a yellow highlight, or select text on a live slide for a color/box picker.
This is the ==most important part== of this slide. Or: ==green:this text==, ==blue:this text==, ==box:this text==
